# Chatbox++

> 简洁美观的 AI 对话桌面应用 · v1.3.2

Chatbox++ 是一款桌面 AI 对话应用。你只需填入自己的 API Key，就能在桌面上与大模型聊天。应用本身不内置任何 AI 服务。

> 🤖 **本项目完全由 AI 开发**，从代码编写到文档撰写，均由 AI 完成。

## ✨ 主要功能

- **多模型管理**：可添加多个模型，分别填写各自的 API Key、地址和模型 ID
- **多会话管理**：可创建多个对话，各自保存历史，支持重命名与删除
- **思考模式**：支持开启 / 关闭思考，并可调节思考强度
- **公式渲染**：支持数学公式显示
- **流式输出**：实时展示回复内容与思考过程
- **主题切换**：浅色 / 深色 / 跟随系统

## 🚀 快速开始

### 环境要求

- Node.js 20.19+

### 安装与运行

```bash
npm install      # 安装依赖
npm start        # 启动应用
```

### 打包成安装包

```bash
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

## 📖 使用指南

1. 打开应用后，点击左下角「设置」→「模型管理」→「添加模型」
2. 填写模型名称、API 地址、API Key 和模型 ID
3. 返回主界面，点击「新对话」，选择模型后即可开始聊天
